# 아이엠뱅크 AI & 블록체인 공모전

금융기관의 **폐쇄망(온프레미스)** 환경에서 금융 문서를 안전하게 다국어로 번역하기 위한 AI 시스템입니다. 핵심은 외부 API에 의존하지 않고 사내 자원만으로 동작하는 경량 번역 모델(**FinHOLLY**)이며, 이를 실제로 쓰는 애플리케이션·브라우저 확장·데모까지 하나의 저장소에 담았습니다.

- **문제의식**: 금융 문서는 개인정보·거래정보 때문에 상용 번역 API로 외부 전송이 어렵다 → 사내에서 직접 학습·서빙하는 번역 모델이 필요
- **접근**: 한국어 → 동남아 5개 언어(베트남·인도네시아·태국·타갈로그·미얀마) 금융 특화 번역을, 공유 인코더 + 분리형(도메인·언어) LoRA 어댑터 구조로 경량화
- **배포**: 어댑터 병합 → CTranslate2 int8 양자화로 외부 통신 없이 서빙

## 핵심 모델: FinHOLLY

일반 번역 모델은 "청산·모집·사모" 같은 금융 용어를 일상 의미로 잘못 번역하는 문제가 있습니다. FinHOLLY는 이를 두 가지 설계로 해결합니다.

1. **분리형 어댑터** — 하나의 NLLB 인코더 위에 *금융 도메인 어댑터*와 *언어 어댑터*를 독립적으로 학습해 조합합니다. 새 언어 추가 시 언어 어댑터만 학습하면 되고 금융 지식은 재사용됩니다.
2. **대조학습(SupCon)** — 같은 용어라도 금융/일상 의미를 구분하도록, 언어 무관 인코더 임베딩에 대조 손실을 걸어 "용어 감각"을 학습합니다.

전체 학습·배포 절차와 평가 방법은 [`FinHOLLY/README.md`](./FinHOLLY/README.md)에 정리되어 있습니다.

## 기술 스택

PyTorch · Hugging Face Transformers · PEFT(LoRA) · NLLB-200-distilled-1.3B · LaBSE · sacreBLEU/FLORES-200 · CTranslate2(int8)

## 라이선스·모델 고지

베이스 모델(NLLB-200, EXAONE 등)은 비상업적 이용 조건이 있을 수 있어, 상용화 시 각 원저작자 라이선스를 확인해야 합니다.
