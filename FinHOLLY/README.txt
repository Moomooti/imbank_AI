FinHOLLY — 온프레미스 금융 번역 프로그램
==========================================

한국어 금융 문장을 베트남어·인도네시아어·태국어·필리핀어·미얀마어로 번역합니다.
완전히 로컬(오프라인)에서 동작하며, 번역할 때 인터넷이 필요 없습니다.


1. 처음 설치할 때 (딱 한 번만)
------------------------------
"install.bat"을 더블클릭하세요.
  - Python 가상환경을 만들고 필요한 프로그램을 설치합니다.
  - Python이 없다는 오류가 나오면, https://www.python.org/downloads/ 에서
    Python 3.11을 설치한 뒤(설치 화면에서 "Add Python to PATH" 체크 필수)
    install.bat을 다시 실행하세요.

  ▶ 인터넷이 안 되는 폐쇄망 PC에 설치하는 경우:
    1) 인터넷이 되는 다른 PC의 FinHOLLY 폴더에서 "make_offline_packages.bat"을
       실행하면 offline_packages 폴더가 생성됩니다.
    2) 이 offline_packages 폴더를 통째로 폐쇄망 PC의 FinHOLLY 폴더 밑에 복사하세요.
    3) 그 다음 폐쇄망 PC에서 install.bat을 실행하면 인터넷 없이 설치됩니다.


2. 사용할 때 (매번)
------------------------------
"실행.bat"을 더블클릭하세요.
  - 몇 초 후 브라우저가 자동으로 열립니다.
  - 안 열리면 브라우저 주소창에 직접 입력: http://127.0.0.1:5000
  - 콘솔 창(검은 창)을 닫으면 서버가 종료됩니다.


3. 모델을 새 버전으로 교체할 때 (개발자용)
------------------------------
아래 두 폴더만 새 버전으로 통째로 바꿔치기하면 됩니다.
코드는 전혀 수정할 필요 없습니다.

  models/finholly_ct2_int8/   <- 번역 모델 (CTranslate2 형식)
  models/tokenizer/            <- 토크나이저 (모델과 세트로 같이 교체)

교체 후 "실행.bat"을 다시 실행하면 새 모델이 바로 적용됩니다.

지원 언어를 추가/제거하고 싶으면 config.py 안의 SUPPORTED_LANGS 딕셔너리만
수정하면 됩니다.


4. 폴더 구조
------------------------------
FinHOLLY/
├── install.bat              최초 1회 설치
├── 실행.bat                  매번 실행 (더블클릭)
├── make_offline_packages.bat 폐쇄망 설치 준비용 (인터넷 되는 PC에서 실행)
├── requirements.txt          필요한 라이브러리 목록
├── config.py                 모델 경로·지원 언어 설정
├── models/
│   ├── finholly_ct2_int8/    번역 모델 (교체 대상)
│   └── tokenizer/            토크나이저 (교체 대상)
├── demo/
│   ├── server.py             웹 서버
│   ├── engine.py             번역 엔진
│   └── static/index.html     화면(UI)
└── README.txt                이 파일


5. 문제 해결
------------------------------
- "Python이 설치되어 있지 않습니다" 오류
  -> python.org에서 Python 3.11 설치, "Add Python to PATH" 체크 필수

- 브라우저에 "연결할 수 없음"이 뜸
  -> 콘솔 창에 "로드 완료" 메시지가 뜰 때까지 몇 초 더 기다린 뒤
     브라우저를 새로고침하세요.

- 번역이 이상하게 나옴 / 모델을 업데이트해야 함
  -> 위 "3. 모델을 새 버전으로 교체할 때" 참고
