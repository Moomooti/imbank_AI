FinHOLLY 페이지 번역 — 크롬 확장 (개발자 모드용)
================================================

1. 번역 서버 먼저 켜기
------------------------------
FinHOLLY 폴더의 "실행.bat"을 더블클릭해서 번역 서버를 먼저 켜두세요.
(http://127.0.0.1:5000 에서 서버가 떠 있어야 확장이 동작합니다)


2. 확장 설치 (최초 1회)
------------------------------
1) 크롬 주소창에 chrome://extensions 입력 후 이동
2) 우측 상단 "개발자 모드" 토글 켜기
3) "압축해제된 확장 프로그램을 로드합니다" 클릭
4) 이 chrome_extension 폴더를 선택

설치되면 툴바에 확장 아이콘이 생깁니다.


3. 테스트
------------------------------
1) 이 폴더의 test_page.html을 크롬에서 열기
   (주소창에 파일 경로를 붙여넣거나 더블클릭)
2) 확장 아이콘 클릭 → 언어 선택(예: 미얀마어) → "번역" 클릭
3) 페이지의 한국어 텍스트가 제자리에서 선택한 언어로 바뀝니다
   (레이아웃/스타일은 그대로 유지됨)
4) "원문 보기"를 누르면 한국어로 되돌아갑니다
5) 다른 언어를 골라서 다시 "번역"을 누르면, 이미 번역된 텍스트가 아니라
   저장해둔 원문 한국어를 기준으로 새로 번역합니다


4. 동작 원리 (간단히)
------------------------------
- popup: 언어 선택 UI
- content script: 페이지의 텍스트 노드를 훑어서 한국어가 있는 것만 골라
  20개씩 묶어 번역 요청, 결과로 텍스트 노드 내용만 교체(DOM 구조는 안 건드림)
- background: 실제 서버 호출 담당 (페이지의 CSP 제약을 안 받기 위함)
- 서버: FinHOLLY/demo/server.py의 /api/translate_batch (CORS 허용됨)


5. 참고
------------------------------
- 일반 웹사이트에서 쓰려면 그 사이트에서 확장 아이콘을 클릭하면 됩니다.
  단, 사이트마다 텍스트가 iframe 안에 있거나 동적으로 로드되는 경우
  (예: React/Vue SPA) 이 기본 버전은 처음 로드된 텍스트만 잡습니다 --
  나중에 MutationObserver를 추가하면 동적 콘텐츠도 대응 가능합니다.
- 문장이 많은 페이지는 CPU 추론이라 다소 시간이 걸립니다(문장당 대략
  0.1~0.3초 내외, 배치 처리 기준).
