# Phase 2 - 태국/미얀마 분절기 폐쇄망 배포용 wheel 목록
#
# 전부 cp311(-win_amd64 또는 py3-none-any) wheel로만 구성되어 있어 컴파일 도구가
# 필요 없다. 배포 서버의 Python은 반드시 3.11 고정 (README.md 참고).
#
# 오프라인 배포 절차:
#   1) 인터넷 되는 PC에서:
#        pip download -r requirements-offline.txt -d wheelhouse --python-version 311 --platform win_amd64 --only-binary=:all:
#      (fasttext-wheel 대신 순정 fasttext를 요구하는 하위 의존성이 없는지 --only-binary=:all: 로 재검증됨)
#   2) wheelhouse/ 폴더를 USB 등으로 폐쇄망에 반입
#   3) 폐쇄망 서버에서:
#        pip install --no-index --find-links wheelhouse -r requirements-offline.txt
#
# 주의: pyidaungsu는 PyPI 메타데이터상 fasttext(소스배포, Windows 컴파일 필요)를
# 요구하지만, 실제로는 fasttext-wheel이 제공하는 동일한 `fasttext` 임포트 이름으로
# 문제없이 동작함을 확인함 (app/mt와 무관, Phase 2 자체 검증 완료).
# 그래서 pyidaungsu는 --no-deps로 설치하고 나머지 의존성을 이 목록에서 직접 명시한다.

fasttext-wheel==0.9.2
